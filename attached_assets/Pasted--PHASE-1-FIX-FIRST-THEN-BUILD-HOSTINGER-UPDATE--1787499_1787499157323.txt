المشكلة 1 — Contract Idempotency

الاختبار الحي أثبت:

First request
→ Contract #435

Same request + SAME idempotency key
→ HTTP 409
→ document number already exists

وهذا خطأ.

المطلوب:

First request:
→ Create Contract

Second identical request:
→ Return SAME Contract
→ idempotent = true
→ HTTP 200
→ No new Contract
→ No new Request
→ No new Customer
→ No Financial Transaction
→ No Journal Entry
الترتيب المطلوب

تحقق من idempotency قبل فحص uniqueness الخاص برقم العقد، بشرط أن تكون العملية السابقة ناجحة ومطابقة لنفس العملية.

لا تضع workaround يخفي المشكلة.

اختبر أيضاً:

Same request
+ Same idempotency key
= same result

ثم:

Same request
+ Different idempotency key
= duplicate/conflict according to business rules

ولا تسمح بإنشاء عقد مكرر.
