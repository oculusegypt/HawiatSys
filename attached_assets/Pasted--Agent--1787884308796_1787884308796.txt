# المطلوب الآن: الاستكمال فقط

## 1. أكمل إصلاح Flash / Loading

المشكلة:

عند فتح معظم الصفحات تظهر حالة/بيانات مؤقتة، ثم تختفي، ثم يظهر المحتوى الحقيقي بعد اكتمال التحميل.

المطلوب معالجة **السبب المشترك** وليس إضافة spinner تجميلي.

راجع التعديلات التي بدأها الـAgent السابق، ثم أكملها.

خصوصًا:

* `App.tsx`
* `SiteSettingsContext.tsx`
* `Login.tsx`
* `AdminLayout.tsx`
* `Home.tsx`
* `Analytics.tsx`
* `Dashboard.tsx`
* أي Auth provider / route guard
* أي global bootstrap/loading state

تأكد أن التطبيق لا يعرض:

`initial/default data → تختفي → real data`

ولا:

`authenticated view → تختفي → login/loading`

ولا:

`login → تختفي → content`

ولا:

`old content → replacement content`

إذا كانت البيانات لم تصل بعد، اعرض Skeleton/loading state مناسبًا بدل بيانات وهمية.

**لا تضف timeout لإخفاء المشكلة.**

ولا تجعل كل التطبيق ينتظر API بلا داعٍ.

# 5. مهم جدًا: المشروع لا يدعم Node في الإنتاج

لا تنس هذه النقطة.

**Production = Hostinger + PHP + SQLite + static frontend.**

لا تضف أي اعتماد تشغيل Production على:

* Node server
* Express
* Node API
* reverse proxy يحتاج Node

Node مسموح فقط كـbuild/test tooling إذا كان موجودًا أصلًا.

أي API Production يجب أن يعمل من:

`PHP router / api-index.php`

`POST /api/admin/analytics/clear`

* 401 بدون auth
* 200 مع admin صالح
* العمل على DB مؤقتة

**لا تعدّل هذا الإصلاح بلا سبب.**
