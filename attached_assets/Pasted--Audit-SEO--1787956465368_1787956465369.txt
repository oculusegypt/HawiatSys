اسمعني كويس: **ممنوع تبدأ Audit جديد، وممنوع تعيد تحليل المشروع أو خطة SEO من الصفر.**

أنت وصلت لمرحلة الإغلاق، والمطلوب الآن **تنفيذ المتبقي فقط ثم إنهاء المهمة**.

الحالة الحالية مثبتة كالتالي:

* SEO Quality Gate = PASS
* Sitemap = 165 رابط فريد
* Canonical ↔ Sitemap parity = 100%
* Assets = 164/164
* TypeScript = PASS
* PHP syntax = PASS
* git diff --check = PASS
* Web/API يعملان
* `cleanflow` public references = 0
* Hostinger archive تم بناؤه
* SEO Metrics موجودة في لوحة التحكم
* Node/PHP metrics endpoint موجود
* `/api/admin/seo/metrics` محمي بـ authentication وهذا **متوقع وليس Bug**

### المطلوب الآن فقط

1. **تحقق أن مؤشرات SEO الجديدة تظهر فعليًا داخل قسم SEO في لوحة التحكم**، وليس فقط أن الكود موجود.
2. إذا كانت المشكلة فقط authentication تمنع الاختبار، استخدم جلسة/مسار الدخول الموجود أصلًا واختبر الصفحة بالطريقة الصحيحة. **لا تجعل endpoint عامًا فقط لكي يمر الاختبار.**
3. تحقق أن المؤشرات تعرض بيانات حقيقية من آخر production build، وليس أرقامًا hardcoded.
4. تحقق من الحالات:

   * PASS
   * WARNING
   * FAIL
   * NOT VERIFIED
5. تحقق أن المؤشرات الأساسية المعروضة تشمل على الأقل:

   * Sitemap
   * Canonical
   * Prerender / HTML
   * JSON-LD / Schema
   * FAQ
   * Meta descriptions
   * SEO images/assets
   * Production URL
   * عدد الصفحات/المسارات
   * Canonical ↔ Sitemap parity
6. تأكد أن Node وPHP يعطون نفس النتائج والمنطق، ولا يوجد اختلاف بين Local وHostinger.
7. شغّل **آخر**:

   * TypeScript
   * PHP syntax
   * SEO quality gate
   * build
   * git diff --check
   * runtime smoke test
8. إذا ظهر أي خطأ حقيقي: **أصلحه مباشرة** ثم أعد الاختبار.
9. إذا لم يظهر خطأ: **توقف فورًا. لا تضف تحسينات جديدة، لا تعيد تصميم UI، لا تعيد هيكلة المشروع، ولا تفتح مهام جديدة.**

### مهم جدًا

لا تعتبر:
`401 Unauthorized`
على endpoint إداري Bug إذا كان الطلب بدون session؛ هذا سلوك أمني صحيح.

ولا تحاول حل أي mismatch قديم إذا كانت النتائج الحالية:
`165 sitemap = 165 canonical`
و
`SEO Quality Gate = PASS`.

### شرط الإغلاق

في النهاية أعطني تقريرًا مختصرًا جدًا فقط:

**IMPLEMENTED**
ما تم تنفيذه.

**VERIFIED**
نتائج الاختبارات النهائية.

**SEO DASHBOARD**
ما هي المؤشرات التي ظهرت فعلًا في لوحة التحكم.

**PRODUCTION**
حالة build + prerender + sitemap + archive.

**REMAINING**
اكتب `NONE` إذا لم يتبق شيء.

إذا كانت كل النتائج PASS، **أنه المهمة ولا تستمر في التحليل أو إضافة شغل جديد.**
