# FINAL EXECUTION COMMAND — CLOSE NOW

استلمت الـ `FINAL EXECUTION REPORT` السابق، وهذه الرسالة هي **أمر التنفيذ النهائي**.

لن أعتمد أي تقرير جديد يحتوي على كلام عام أو إعادة استكشاف أو خطة جديدة.

## نفّذ الآن فقط

لديك بيانات FTP اللازمة للوصول إلى:

```text
Host: 92.113.19.25
Port: 21
Remote Directory: public_html
```

**استخدم بيانات الاعتماد التي زُودت بها في السياق، ولا تطبع كلمة المرور أو أي Secret في الـ logs أو التقرير.**

### المسار الإلزامي

```text
1. FTP Authentication
2. Verify public_html access
3. Create production backup
4. Verify backup exists and is readable/integral
5. ONLY IF backup is verified → deploy cleanflow-services-hostinger.zip
6. Verify uploaded files
7. Verify deployed SHA / BUILD_INFO
8. Live API Health
9. Live authentication check
10. One complete Live E2E
11. Database integrity
12. Financial reconciliation
13. Final report
```

## ممنوع

* لا تعيد Discovery.
* لا تعيد قراءة `MEMORY.md`.
* لا تعيد تحليل الملفات التي تم تحليلها.
* لا تعيد تنفيذ الاختبارات التي ثبت نجاحها إلا إذا كانت Regression check ضرورية.
* لا تعدّل الكود بدون Bug قابل لإعادة الإنتاج.
* لا تنشئ خطة جديدة.
* لا تعمل Refactoring.
* لا توسّع Scope.
* لا تنشئ بيانات اختبار في Production قبل Backup موثق.
* لا تعتبر فشل الـ Test Harness Bug في التطبيق.
* لا تحاول FTP عشرات المرات.
* لا تدّعي PASS بدون Assertion حقيقي.

```text

→ completed
→ synchronization
→ Invoice
→ Payment 500

```

ثم:

```text
Same Idempotency-Key
→ no duplicate payment
→ same payment identity
→ payment count unchanged
```

ثم:

```text
Payment > remaining
→ rejected
```

ويجب أن تكون النتائج مبنية على قيم فعلية، وليس مجرد HTTP 200.

## Work Orders

تحقق فقط من:

```text

Pickup   → work_order +1
Emptying → work_order +1
```

والأهم:

```text
service_requests delta = 0
```

إذا كانت هذه النتيجة صحيحة، لا تفتح ملفات إضافية ولا تعيد تصميم المسار.
