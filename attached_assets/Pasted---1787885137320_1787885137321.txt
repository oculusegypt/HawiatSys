## الحالة الحالية

تم بالفعل:

* معالجة مسار Analytics في PHP.
* إصلاح `POST /api/admin/analytics/clear` في Hostinger.
* التحقق من 401/200 على نسخة اختبار.
* نجاح PHP lint.
* نجاح typecheck سابقًا.
* نجاح build وHostinger archive سابقًا.
* نجاح SEO gate سابقًا.
* بدء إصلاح Flash/loading في التطبيق.
* تعديل `App.tsx`.
* تعديل `SiteSettingsContext.tsx`.
* تعديل `Dashboard.tsx`.
* تعديل `Home.tsx`.

# 2. أنهِ Flash/loading

الهدف النهائي فقط:

عند فتح أي صفحة، لا يظهر للمستخدم محتوى خاطئ ثم يختفي ثم يظهر المحتوى الحقيقي.

خصوصًا:

* Login
* Home
* Dashboard
* Analytics
* Reports
* Admin
* صفحات الخدمات
* المقالات
* صفحات المناطق

يجب أن تكون الحالة:

**Loading/Skeleton → المحتوى الحقيقي**

وليس:

**محتوى افتراضي → اختفاء → محتوى حقيقي**

ولا:

**بيانات صفرية → اختفاء → البيانات الحقيقية**

ولا:

**حالة Auth خاطئة → اختفاء → الحالة الصحيحة**

لا تستخدم:

* timeout
* setTimeout
* hacks
* CSS لإخفاء المشكلة
* forced reload

أصلح السبب.

إذا كانت التعديلات الحالية كافية، **لا تغيّرها**.
