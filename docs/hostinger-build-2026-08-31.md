## ما تم إكماله

### إصلاح طلب structured data

- إضافة `GET /api/structured-data` إلى PHP API في الأرشيف.
- دعم اختيار الصفحة عبر `?path=...` مع توحيد المسار والتصفية حسب النطاق.
- إخراج JSON-LD بصيغة `@context` و`@graph` متوافقة مع مسار Node.
- حماية الأنواع المدعومة من إدخال أنواع غير معتمدة.
- تنظيف نصوص FAQ من HTML وتحويلها إلى `Question` و`Answer` صالحين.
- تطبيق اسم الشركة الحالي داخل البيانات المتداخلة، مع حماية ترميز UTF-8 عند الإخراج.

هذا يغلق الخطأ الذي ظهر في المتصفح:

`GET /api/structured-data?path=%2F 404 (Not Found)`

### توحيد مدة إيجار الحاوية

- مشاركة ثابت واحد بين النموذج الكامل ونافذة الطلب السريعة.
- تثبيت القيمة على:

  `حتى 10 أيام أو امتلاء الحاوية، أيهما أقرب`

- منع إرسال قيم قديمة أو غير مدعومة من واجهة العميل.
- توضيح الحد التشغيلي داخل النموذج للمستخدم.

### توحيد اسم الشركة في محتوى الصفحة الرئيسية

- تطبيق استبدال الاسم القديم داخل النصوص والمصفوفات والكائنات المتداخلة في
  `homepage_content`، وليس في الحقول النصية السطحية فقط.
